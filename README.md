# Slack - React + Vite 

## Proyecto privado construido con React y Vite, que integra librerías populares para la interfaz de usuario y la gestión eficiente de datos.

## Tecnologías

- React 18
- Vite
- @mui/material + @mui/icons-material
- @emotion/react + @emotion/styled
- React Query (@tanstack/react-query)
- ky (cliente HTTP)
- react-router-dom (rutas)
- ESLint para linting

---

## Requisitos

- Node.js (recomendado usar [nvm](https://github.com/nvm-sh/nvm))
- pnpm (gestor de paquetes)

---

## Instalación y puesta en marcha

```bash
# Instalar y usar Node.js versión 18 con nvm
nvm install 18
nvm use 18

# Clonar el repositorio y moverse al directorio
git clone <url-del-repo>
cd front

# Instalar dependencias
pnpm install

# Levantar servidor de desarrollo
pnpm run dev
pnpm dev
```
